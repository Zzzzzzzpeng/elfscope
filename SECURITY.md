# Security policy

ELFscope is intended for defensive static analysis. It does not execute inspected files.

## Reporting a security issue

Please do not publish sensitive details until a fix has been coordinated. For a public project, use the repository's private security-reporting mechanism where available. If that mechanism is unavailable, open a minimal issue that does not include sensitive sample data and clearly states that the report concerns the security of ELFscope itself.

Do not upload confidential binaries, credentials, or private customer data to a public issue tracker.
